# Charu Sharma — Java Full-Stack Developer Portfolio

An immersive, highly interactive personal portfolio website inspired by the Slush design system and built with React, Three.js, and Tailwind CSS.

## 🚀 Quick Deployment Options

### Option 1: Deploy on Vercel (Recommended, 1-Click)
1. Push this project folder to a GitHub repository.
2. Go to [vercel.com](https://vercel.com) and click **Add New Project**.
3. Import your GitHub repository.
4. Framework Preset: **Vite**.
5. Click **Deploy**. Your portfolio is live in under 1 minute!

### Option 2: Deploy on Netlify (Drag & Drop)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the dist/ folder directly onto the page.
3. Your website is instantly published with a live URL!

### Option 3: Run Locally
`ash
npm install
npm run dev
`
To create a production build:
`ash
npm run build
`
The optimized production files will be output to dist/.

## 🛠️ Tech Stack & Features
- **Frontend**: React 18, Vite 6, Tailwind CSS
- **3D Graphics**: Three.js WebGL Inflatable Electric Blue Ribbon
- **Design Language**: Slush Visual Identity (Solid colors, Tactile stickers, Oversized display typography)
- **Icons**: Authentic Brand SVGs (Java, Spring Boot, React, MySQL, GitHub, LinkedIn, etc.)
- **Accolades & Features**: TAP Academy Internship Pass, 3rd Place Award Confetti Cannon, Architecture Pipeline Inspector
